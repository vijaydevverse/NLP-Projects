# 🚀 NLP-Projects-Portfolio

A collection of Natural Language Processing (NLP) and AI-based projects built using Python. These projects focus on text understanding, speech processing, document analysis, and intelligent automation systems. The repository demonstrates real-world applications of NLP such as summarization, speech recognition, semantic matching, and voice-based AI interaction.

---

## 🧠 Tools & Technologies

- Python  
- Natural Language Processing (NLP)  
- Scikit-learn  
- Pandas & NumPy  
- Streamlit  
- SpeechRecognition  
- Pyttsx3 (Text-to-Speech)  
- PyPDF2  
- TF-IDF Vectorization  
- Cosine Similarity  
- OpenCV (basic AI integration)

---

## 📌 Projects Included

- AI-based Resume Matching System using NLP and similarity scoring  
- PDF Document Summarizer for exam and work notes generation  
- Voice-Controlled AI Assistant for automation and web tasks  
- AI Meeting Assistant for speech-to-text conversion and summarization  
- Speech Emotion Recognition System for detecting sentiment from voice input  

---

## ⚙️ Features

- Resume and job description semantic matching  
- Automatic PDF text summarization  
- Voice-based AI interaction system  
- Speech-to-text processing for meeting transcription

## 🚀 Installation & Usage

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/nlp-projects-portfolio.git
cd nlp-projects-portfolio
```

---

### 2️⃣ Install dependencies
```bash
pip install -r requirements.txt
```

---

### 3️⃣ Run Streamlit apps (if applicable)
```bash
streamlit run app.py
```

---

### 4️⃣ Run Python scripts
```bash
python app.py
```
